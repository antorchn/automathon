Règles de l'Arène Automathon ({{ settings.game_version }})

Format de l'agent

Téléchargez le kit officiel sur antorchn/automathon (release v1.0.0).

  • Archive .zip d'au plus {{ settings.submission_max_mb }} Mo.
  • Un unique dossier racine <nom>/ contenant agent.py.
  • agent.py définit ParticipantAgent avec get_action(state: GameState) -> AIAction.
  • Bibliothèques du kit 1.0.0 uniquement (numpy, numba, torch CPU, stable-baselines3, pydantic…).
  • Aucune connexion réseau, écriture autorisée uniquement dans /tmp (100 Mo).

Limites d'exécution

  • Chargement et préchauffage : {{ settings.agent_load_timeout_s }} s max.
  • Mémoire conteneur : {{ settings.agent_memory_mb }} Mo (sans swap), 1 vCPU.
  • Temps CPU moyen de décision : {{ settings.decision_mean_ms_limit }} ms par partie.
  • Délai de réponse par décision : {{ settings.decision_timeout_ms }} ms (sinon l'action précédente est gardée).
  • Exceptions tolérées : {{ settings.max_exceptions_per_game }} par partie (au-delà : forfait).
  • Durée maximale : {{ settings.max_frames }} frames (70 s de jeu).

Classement Elo et placement

  • Validation : {{ settings.validation_games }} parties contre dummy_bot.
  • Placement : {{ settings.placement_opponents }} adversaires (ou tous si moins de {{ settings.placement_opponents }} classés), {{ settings.placement_maps_per_opponent * 2 }} parties chacun.
  • Elo calculé globalement par maximum de vraisemblance (modèle de Bradley-Terry), avec {{ settings.anchor_agent_name }} fixé à {{ settings.anchor_elo|int }}.
  • Un agent dont la marge (±1,96σ) dépasse {{ settings.provisional_margin|int }} Elo est marqué provisoire.
  • Cooldown : {{ settings.cooldown_minutes }} minutes entre deux envois par compte.

Données personnelles

  • Connexion par OAuth GitHub sans permission supplémentaire (profil public uniquement).
  • Données conservées : identifiant numérique GitHub, login, URL d'avatar, date d'inscription, et adresse IP des envois pendant 30 jours uniquement (garde-fou anti-abus). Aucun e-mail n'est lu ni stocké.
  • Vous pouvez à tout moment supprimer votre compte, vos agents et vos replays depuis Mon compte.
